Overview

Cortex PS Toolkit

Professional-services tooling for Cortex XSOAR and Cortex XSIAM tenants — credentials, content cache, cross-tenant copy, playbook analysis, and platform administration.

API Profiles

Register tenant URLs and API keys, validate connectivity, and select the active profile for all tools.

XQL Query Tool

Run live XQL against XSIAM/XDR/AgentiX tenants with presets, visualisations, and query history.

List Tools

Refresh, browse, copy, and delete Cortex lists between tenants with conflict preview.

Script Tools

Cache automation scripts, copy custom scripts across tenants, and bulk delete with safeguards.

Playbook Tools

Refresh playbooks and scripts together, analyse structure, refactor with extract-multi, and copy playbooks or component trees.

Integrations

Browse definitions, instances, and commands; copy or delete custom integration definitions; manage the credential vault.

Object Setup

Incident fields, types, layouts, classifiers, and pre-process rules — refresh, copy, delete, and cross-tenant Object Bundle workflows.

Indicators

IOCs, BIOCs, and correlation rules — list, copy, and delete with platform-aware API routing.

User Administration

RBAC users, roles, groups, and API keys where supported on the active tenant.

Settings

Toolkit preferences such as cache TTL and concurrency limits.
